User analytics — setup guide

EuroFuelPrices is a static site served from GitHub Pages — there is no server-side access log. To understand how visitors use the app, you need a lightweight client-side analytics solution. Three recommended options below.

📊 GoatCounter Free · Privacy-first

Simple, open-source, GDPR-compliant. No cookies. Free for public sites. Shows page views, countries, referrers, device types. Takes 2 minutes to set up.

No cookies
GDPR OK
Open source


1. Register at goatcounter.com (free for public sites)
2. Add this to index.html before </body>:

<script data-goatcounter="https://YOUR.goatcounter.com/count" async src="//gc.zgo.at/count.js"></script>

3. To track fuel type filters and Near Me usage, emit custom events:

window.goatcounter?.count({ path:'fuel-filter/DIESEL', title:'Filter: Diesel' }); window.goatcounter?.count({ path:'nearby-used', title:'Near Me tapped' });

🌐 Plausible Analytics €9/mo · Best UX

Best-in-class privacy-friendly analytics. Beautiful dashboard. Custom events for fuel types, Near Me, country filters. EU-hosted (Estonia). GDPR/CCPA compliant out of the box.

EU-hosted
Custom events
Best dashboard


<script defer data-domain="your-domain.github.io" src="https://plausible.io/js/script.tagged-events.js"></script>

Then track custom events:

// When Near Me is used: window.plausible?.('Near Me', { props: { action:'locate' } }); // When a fuel type is selected: window.plausible?.('Fuel Filter', { props: { fuel: fuelType } }); // When a country is filtered: window.plausible?.('Country Filter', { props: { cc: countryCode } });

☁️ Cloudflare Web Analytics Free forever

100% free, requires a Cloudflare account (free). Works without proxying the site. Cookie-less. Shows Core Web Vitals, pages, countries, referrers. No custom events on free plan.

Free
Core Web Vitals
No config


1. Go to Cloudflare Dashboard → Web Analytics → Add site
2. Add the snippet to index.html:

<script defer src='https://static.cloudflareinsights.com/beacon.min.js' data-cf-beacon='{"token": "YOUR_TOKEN"}'> </script>

No server changes needed. Works on any static host including GitHub Pages.
