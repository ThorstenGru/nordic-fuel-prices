# Facebook: Page + group plan (free, organic only)

No paid campaigns (project rule: everything free). Owner creates the Page and posts; Claude drafts.
Numbers below are medians from https://eurofuelprices.com/europe/ on 2026-11-11 (EUR per litre) — **refresh them from that page right before posting**.

## 1. Create the Page (owner, ~5 minutes)
1. facebook.com -> menu -> **Pages** -> **Create new Page** (or facebook.com/pages/create).
2. **Page name:** `EuroFuelPrices`  ·  **Category:** `Website` (or `Product/Service`).
3. **Bio (max 101 characters):** `Live fuel prices across Europe. Free map, no account, no ads. eurofuelprices.com`
4. Profile picture: `docs/facebook/profile.png`  ·  Cover: `docs/facebook/cover.png` (1640x624; keep text centred).
5. Page -> **Edit Page info**: Website `https://eurofuelprices.com`, short description below, **Call-to-action button** `Learn more` -> the same URL.
6. Username (handle): try `eurofuelprices`.

**About text:**
> EuroFuelPrices shows live petrol and diesel prices at 120,000+ stations in 40+ European countries, on a free map with no account and no ads. We also publish a daily ranking of country prices and cross-border comparisons (Sweden vs Denmark, Germany vs Poland and more): https://eurofuelprices.com/europe/

## 2. First five posts (post one per day; link goes in the post text, picture = the share card of that page)
1. **Intro** — "We built a free fuel price map for Europe: live prices at 120,000+ stations in 40+ countries, no account, no ads. Try it: https://eurofuelprices.com"
2. **Cheapest/most expensive** — "Where is petrol cheapest in Europe today? Malta €1.34/L, Poland €1.39/L ... and Norway at €2.25/L (median station price, 95 octane). Full ranking, updated daily: https://eurofuelprices.com/europe/"
3. **Border post (Germany–Poland)** — "Petrol 95 is about €0.52 per litre cheaper in Poland than in Germany today (median station) — roughly €26 on a 50 L fill-up. Is the detour worth it? https://eurofuelprices.com/europe/fuel-prices-germany-vs-poland/"
4. **Border post (Sweden–Denmark)** — use the live numbers from https://eurofuelprices.com/europe/fuel-prices-sweden-vs-denmark/ and the page's picture.
5. **Feature** — "Border-run calculator: it includes the extra driving, so you see if the trip really saves money." + link to the map.

Add the page's share picture as the post image (right-click the `og:image`, or use the picture Facebook generates from the link preview — it will pick `/og/<page>.png` automatically).

## 3. Groups (where the real reach is) — owner posts, one group per day, read the rules first
Good targets: husbil/husvagn/campervan groups, border commuters (Öresund, DE-DK, DE-PL, AT-CZ), trucker/yrkesförare groups, local "köp/sälj/prat" town groups, expat groups.
Template (adapt to language and rules; answer questions in the thread; never spam the same text twice):
> I made a free fuel price map for Europe (no account, no ads). Today's example: <one real number from /europe/>. If you drive across a border for fuel there is a calculator that includes the extra driving. Feedback on wrong or missing stations is very welcome: https://eurofuelprices.com

## 4. Cadence and measuring
- 3 posts a week (Mon: ranking, Wed: border pair, Fri: tip/feature). Reuse the daily numbers from `/europe/`.
- In Search Console/Cloudflare Web Analytics, look at referrals from `facebook.com` after 2 weeks; keep what gets clicks.
- Honest expectation: a new Page has tiny organic reach. Groups and shares do the work; the Page is a home to link to.
